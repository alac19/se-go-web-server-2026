## 一、测试概述

### 1.1 测试目标
验证本 Go 反向代理服务器在功能、性能方面满足需求规格说明书的要求，确保以下核心能力：
- HTTP/HTTPS 双协议监听与转发
- 轮询负载均衡（线程安全）
- 动态健康检查（后端自动剔除/恢复）
- 结构化日志记录（JSON 格式，输出到控制台和文件）
- 错误处理（502/503 状态码）
- 高并发下的吞吐量和延迟表现

### 1.2 测试范围

| 测试类型 | 覆盖范围                                                           |
| -------- | ------------------------------------------------------------------ |
| 单元测试 | 配置加载模块、负载均衡模块、健康检查模块、反向代理模块、日志模块   |
| 系统测试 | 集成测试（模块协作）、端到端测试（完整用户场景）、功能正确性验证   |
| 性能测试 | 不同并发级别下的 QPS、平均延迟、P99 延迟、错误率；长时间负载稳定性 |

## 三、测试策略

### 3.1 测试方法
- **单元测试**：使用 Go 标准 `testing` 包编写测试用例，运行 `go test -v -cover` 获取覆盖率和结果。
- **系统测试**：通过手动操作（`curl`、浏览器）模拟真实客户端请求，观察代理日志和响应内容，验证功能完整性。
- **性能测试**：使用 `ab` 和 `go-wrk` 工具对 HTTP 8080 端口进行压测，每个并发级别执行 3 次取平均值；每次测试后等待 1 分钟避免热累积；记录 QPS、延迟（平均/P99）、错误数。

### 3.2 测试通过标准
- **单元测试**：所有测试用例通过，核心模块（config, lb, health, proxy, log）代码覆盖率 ≥ 80%。
- **系统测试**：需求规格说明书中的 FR-01 至 FR-07 全部验证通过，无功能性缺陷。
- **性能测试**：QPS ≥ 3000，平均延迟 ≤ 30ms，P99 延迟 ≤ 100ms，错误率 = 0%。

| 编号 | 测试项         | 操作步骤                                         | 预期结果                                                   |

## 五、测试执行计划

1. **单元测试执行**：运行 `go test -v -cover ./...`，记录每个包的通过情况和覆盖率，截图或复制输出。
2. **系统测试执行**：按照 ST01~ST08 顺序手动执行，使用 `curl` 命令并观察响应和日志，必要时保存截图。
3. **性能测试执行**：
   - 先启动三个后端服务（9091/9092/9093）。
   - 启动 Go 反向代理（`go run ./src/main.go`）。
   - 依次执行 PT01~PT05，每个并发级别运行 3 次，每次后等待 1 分钟。
   - 保存每次输出的文本文件到 `test_results/`（命名格式：`go_ab_c{并发}_n{请求数}_run{轮次}.txt`）。
   - 运行 PT06、PT07 稳定性测试，记录输出。
4. **数据汇总**：将性能测试关键指标填入 Excel 表格，计算平均值和标准差。
5. **测试报告编写**：汇总单元测试、系统测试、性能测试结果，形成最终报告。
